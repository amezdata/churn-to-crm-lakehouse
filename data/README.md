# data

`synthetic/brainlab/` holds the BrainLab greenfield sources generated by `synthgen` (CSV + JSON Lines). There is no real PII. They can be regenerated:

```powershell
python scripts/generate_brainlab.py --seed 42
```

The committed files use seed 42 and scale `small`, with the Bronze mess on.

`synthetic/stemstar/` holds synthetic STEMStar extracts from `stemstar_synth`. It is not committed: `pipeline run`
creates it on first use, or run `python -m stemstar_synth`. See [`src/stemstar_synth/README.md`](../src/stemstar_synth/README.md).

The real STEMStar extracts (pseudonymised Excel) are not part of this repository. Private inputs go under `data/raw/`
(gitignored). Loading them into the Postgres silos is `scripts/load_supabase.py`; the schema is `supabase/01_silos.sql`.
